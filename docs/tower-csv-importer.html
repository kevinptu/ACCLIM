Import flux tower GPP

Select a Quanterra CSV. Processing stays in your browser. Valid GPP records with INCOMING_SHORTWAVE_RADIATION > 0 are averaged by local calendar month, using MIDPOINT_DATETIME. Supplied negative GPP and gap-filled values are retained. Missing values are excluded.



Paste the result into “Tower CSV data” in ACCLIM's inputs and click “Use CSV coordinates and dates”. Review or edit the populated fields, then Run ACCLIM and select “Add Flux tower GPP”. These are whole-footprint observations, not adjusted to a selected cover fraction.
