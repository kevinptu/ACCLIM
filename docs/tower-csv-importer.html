Tower weather fields (optional model inputs)

Full-day weather is summarized separately from daytime GPP. A model period requires every half-hour/hour of temperature, humidity, shortwave, pressure, rainfall and both corrected heat fluxes (LE_CORR + H_CORR). Missing inputs leave that period unavailable. FLUXNET _F fields may include reanalysis filling; choose the supplied series appropriate to your diagnostic.

Model energy input = LE_CORR + H_CORR, summed only where both values exist. P_F and PA_F are preferred.

Choose a file to begin.

Means use every finite GPP value when shortwave > 0, including gap-filled and negative values. No coverage cutoff is applied. Missing GPP (%) is the percentage missing among records with known positive shortwave. Missing radiation and absent timestamps are reported separately because their daytime status is unknown. NT/DT identify partitioning methods, not the hours averaged.

Paste the summary into ACCLIM’s Tower CSV data, choose Use CSV coordinates and dates or Load with current settings, after pasting press Tab to commit the text, then Run ACCLIM and enable the tower chart series. Observations represent the whole footprint; partial-month observations may differ from full-month model estimates.

Daily weather gives the most temporal detail and more model computation and copied data. Weekly or monthly reduces run size. Saved JSON retains daily weather so you can change this choice later. Older monthly-only JSON requires reprocessing the original CSV/ZIP for finer timesteps.
